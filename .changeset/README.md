# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets)

We have a quick list of common steps to get you started:

## Adding a changeset

When you're making a change to a package, you should add a changeset to document the change. To do this,
run:

```bash
pnpm changeset
```

This will prompt you with some questions, and then create a changeset file that you should commit.

## Releasing

When you're ready to release packages, there are two steps:

1. **Version packages** - This updates the version numbers of packages based on the changesets:

```bash
pnpm version
```

2. **Publish packages** - This publishes the packages to npm:

```bash
pnpm release
```

## What are changesets?

A changeset is a file that contains information about a change you've made. It has:

- The packages you're changing
- The type of change (major, minor, patch)
- A summary of the change

When you run `pnpm version`, changesets will:

- Update the version numbers of the changed packages
- Update the CHANGELOG.md files
- Remove the changeset files

When you run `pnpm release`, changesets will:

- Publish the packages to npm
- Create a git tag for the release
